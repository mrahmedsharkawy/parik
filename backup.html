نسخة الصفحة هي Application Backup مشفرة. تم إعداد نسخة Disaster Recovery يومية مستقلة على جهاز الشركة تشمل PostgreSQL وملفات Storage. المتصفح لا يستطيع فحص Windows Task Scheduler أو محتويات القرص D لأسباب أمنية، لذلك حالة النسخة المحلية يتم التحقق منها من ملف manifest وSHA-256 على الجهاز.

خطة التعافي واختبار الاستعادة

لا تختبر Full Restore على Production. استخدم مشروع Supabase تجريبيًا، استعد المخطط أولًا، ثم البيانات وAuth وStorage، وشغّل فحص أعداد السجلات والـchecksums والعلاقات قبل اعتماد النسخة.
